DEBUGGING PRACTICE

อ่าน Error ให้เป็น

Error ไม่ได้บอกว่าเรา “เขียนไม่เก่ง” — มันบอกว่า Python ไปต่อไม่ได้ตรงไหน

โจทย์ฝึกคิดมี Bug ซ่อนอยู่ 1 จุด

หาค่าเฉลี่ยของคอลัมน์ overall

average = df["overal"].mean()
print(average)
KeyError: 'overal'

Python หา “คอลัมน์ชื่อ overal” ไม่เจอในตาราง

วิธีอ่านทีละส่วน

กดรันโค้ด แล้วเราจะค่อย ๆ แยกความหมายของ Error ด้วยกัน
